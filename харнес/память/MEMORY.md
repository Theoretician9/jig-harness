# MEMORY.md — указатель памяти проекта

Грузится каждую сессию. Содержимое записей здесь НЕ дублируется — только
таблица срабатываний и указатель. Записи — файлы рядом, один факт = один файл.

## ТАБЛИЦА СРАБАТЫВАНИЙ: когда → что проверить

| когда происходит вот это | проверить себя |
|---|---|
| пришло сообщение владельца, собираюсь начать работу молча | сначала ack ≤30с в канал — [[feedback-communication]] |
| отправил «сейчас посмотрю/сделаю» и хочу закончить ход | анонсировал — продолжай, ход не кончен — [[feedback-communication]] |
| хочу задать вопрос или показать варианты | сообщением в канал с номерами, не интерактивным инструментом — [[feedback-communication]] |
| собираюсь отправить владельцу путь к файлу на сервере | владелец путь не откроет — вложением — [[feedback-communication]] |
| пишу шестой `if` под новый частный случай | неверная структура данных, не место для `if` — [[feedback-code-bar]] |
| тесты позеленели и тянет отчитаться «готово» | «тест зелёный» ≠ «сделано»: живая проверка, статус `test` — [[feedback-test-not-done]] |
| сторож отменил команду и тянет обойти его | сторож — источник истины; читать причину, не обходить — [[feedback-command-bans]] |
| собираюсь запускать `claude`/`pytest`/`docker` из скрипта или фоном | сверить с запретами и их причинами — [[feedback-command-bans]] |
| собираюсь выкатывать, ротировать сессию или делать необратимое | это развилка полуавтомата: анонс и подтверждение — [[feedback-semi-auto]] |
| анонс отправлен, хочется начать, «пока владелец читает» | без записи согласия в confirmations.jsonl действия нет — [[feedback-semi-auto]] |
| закончил шаг пайплайна (спека готова, тесты красные, код на ревью, выкачено) | обновить SESSION-HANDOFF за сегодня — [[feedback-handover-discipline]] |
| берусь за архитектуру, крупный рефакторинг или сложный баг | поднять усилие: /effort max до старта — [[feedback-effort-max]] |
| ловлю себя на «simplest / should I continue / not my changes» | маркер среза угла: перечитать файл, обосновать, продолжить — [[feedback-effort-max]] |
| собираюсь читать в контекст большой файл, лог или «все файлы подряд» | обработать скриптом, в контекст — вердикт — [[feedback-data-via-scripts]] |
| пишу тест/гейт или читаю в чужой описи «зелёный, неудач 0» | проверка обязана создавать своё условие, а не совпадать с машиной — [[проверка-создаёт-условие]] |
| собираюсь удалить файл внутри data/backup/secrets — «он же один» | И-1 про потерю данных, а не про рекурсию: решает владелец — [[и-1-удаление-файла]] |
| пишу код, шлющий текст в tmux-панель агента | без `-l --` tmux примет текст за имя клавиши, Enter — отдельным вызовом — [[tmux-send-keys-имя-клавиши]] |
| пишу скрипт, который копирует пачку файлов в чужое дерево | права проверить ДО первой записи: полуобновлённое дерево хуже необновлённого — [[полуобновлённое-дерево]] |
| правлю файл харнеса (scripts/, харнес/, CLAUDE.md, settings.json) | править ПАКЕТ и разложить: правка только в проекте умрёт при раскладке — [[пакет-источник-раскладки]] |
| собираюсь сохранить копию конфига рядом с оригиналом в *.d/ | каталог конфигов — список включённого: копия станет вторым конфигом — [[бэкап-рядом-с-конфигом]] |
| беру лок дескриптором и запускаю демона (tmux, агента) | потомок наследует дескриптор и держит лок вечно — сторож мёртв и молчит — [[лок-утёк-в-потомка]] |
| пишу в shell присваивание с кириллицей в имени переменной | bash такие имена не берёт и печатает ЗНАЧЕНИЕ в ошибку (так утёк токен) — [[кириллица-в-именах-bash]] |
| сторож прислал «заверши сессию и выйди» — тянусь к --rotate-now | смену уже ведёт он: доделать, закоммитить и выйти /exit — [[уход-заказан-не-мной]] |
| дописал строку в системный конфиг (юнит, cron, sysctl) руками | кто скажет, что строка принята? неверная секция игнорируется молча — [[настройка-игнорируется-молча]] |
| контекст близок к компакту / пришла команда ротации | STATE.md перезаписать, handover дописать — [[feedback-handover-discipline]] |
| владелец задал правило («всегда», «никогда», «я говорил», «не хочу») | занести ДОСЛОВНО в память/УКАЗАНИЯ.md, иначе умрёт с сессией — [[указание-умерло-с-сессией]] |
| собираюсь завершить свою сессию (выход, `/exit`, kill панели) | выход и подъём смены — одно действие: `session-warden.sh --rotate-now` — [[уход-без-смены]] |
| пишу условие «пока рядом человек — не вмешиваюсь» | у уважения обязан быть срок и мера, иначе механизм выключен навсегда — [[приаттаченный-не-навсегда]] |
| пишу ожидание в тесте (`rc == 0`, точная строка) | не зависит ли оно от того, кто запускает: прогнать из `env -i` и из-под юнита — [[тест-зависит-от-запускающего]] |
| проверяю живость агента через `pane_current_command` | сперва `tmux has-session`: выход агента закрывает панель вместе с сессией — [[выход-закрывает-панель]] |
| завожу резервный путь (второй демон, `Restart=always`, таймер вместо cron) | выписать, что делал прежний путь ПОМИМО главного, и провести каждый пункт по новому — [[носитель-без-обязанностей]] |
| пишу условие сигнала («очередь непуста», «задач не в done больше нуля») | при какой ЗДОРОВОЙ жизни оно тоже истинно? тогда сузить признак и завести различение в ДАННЫХ — [[сигнал-без-различения]] |

## Указатель

- [Общение с владельцем](feedback-communication.md) — Telegram единственный канал; ack, «анонсировал — продолжай», без интерактива, вложения
- [Планка кода](feedback-code-bar.md) — Торвальдс + SOLID по духу; признаки просевшей планки
- [Тест зелёный ≠ сделано](feedback-test-not-done.md) — статус `test` до живой проверки владельцем
- [Запреты на команды](feedback-command-bans.md) — почему guard_bash отменяет; сторож — истина, эта запись — причины
- [Полуавтомат](feedback-semi-auto.md) — какие развилки требуют анонса и как читать подтверждения
- [Дисциплина рубежей](feedback-handover-discipline.md) — SESSION-HANDOFF на каждом рубеже шага пайплайна
- [Усилие на сложных задачах](feedback-effort-max.md) — /effort max до старта критичных задач; маркеры «ленивого» ответа
- [Данные — скриптом](feedback-data-via-scripts.md) — большие файлы/логи не в контекст: обработать кодом, вернуть вердикт
- [Проверка создаёт условие](проверка-создаёт-условие.md) — три «зелёных» селфтеста пакета, покрасневших на живом сервере: зависимость от состояния машины
- [И-1 и удаление файла](и-1-удаление-файла.md) — `rm -f` по секрету проходил мимо сторожа; правило чинено кодом, цена названа
- [tmux: текст как имя клавиши](tmux-send-keys-имя-клавиши.md) — сообщение «Enter» становилось нажатием, а Enter одним вызовом терялся: только `send_to_pane`
- [Полуобновлённое дерево](полуобновлённое-дерево.md) — раскладка падала на `cp` посередине: права проверяются до первого копирования
- [Пакет — источник раскладки](пакет-источник-раскладки.md) — правка только в проекте затирается; держится гейтом package_sync и журналом ИЗМЕНЕНИЯ.md
- [Бэкап рядом с конфигом](бэкап-рядом-с-конфигом.md) — копия в /etc/logrotate.d стала вторым конфигом и сломала починку
- [Кириллица в именах bash](кириллица-в-именах-bash.md) — переменные только латиницей; ошибка печатает значение, так утёк токен бота
- [Анонс — не команда](анонс-не-команда.md) — вопрос, ждущий ответа, записанный как исполненное действие, задавил ротацию на 2 часа; окно дошло до 114%
- [Уход без смены](уход-без-смены.md) — сессия вышла сама, преемника поднять было некому: уходить только через `--rotate-now`
- [Приаттаченный — не навсегда](приаттаченный-не-навсегда.md) — постоянный ssh-клиент отменял подъём агента бессрочно; мера — активность панели, а не наличие клиента
- [Тест зависит от запускающего](тест-зависит-от-запускающего.md) — путь ждал rc=0, который получался только из сессии агента; из systemd краснел при исправном коде
- [Выход закрывает панель](выход-закрывает-панель.md) — сессия, созданная командой, исчезает вместе с агентом: ждать «снова bash» бесполезно
- [Носитель без обязанностей](носитель-без-обязанностей.md) — новый путь исполнения делает главное дело и молчит про остальное: всё зелёное, работа стоит
- [Сигнал без различения](сигнал-без-различения.md) — сторож смотрит на признак, истинный и у здоровой системы: горит всегда, значит не несёт сведений
- [Уход заказан не мной](уход-заказан-не-мной.md) — два сторожа на одну смену: второй встал за локом первого, оба замерли, снаружи тишина
- [Настройка игнорируется молча](настройка-игнорируется-молча.md) — ключ в неверной секции юнита не работал четверо суток; гейт установки правки после установки не видит
- [Лок утёк в потомка](лок-утёк-в-потомка.md) — tmux-сервер унаследовал дескриптор лока и держал его вечно: сторож сессий был мёртв 40 минут
- [Указание умерло с сессией](указание-умерло-с-сессией.md) — трёхуровневая память: УКАЗАНИЯ.md грузится всегда, гейт scripts/указания.py
