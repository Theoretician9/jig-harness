# Мобильная петля: смотреть, а не упоминать

Тип: reference. Появилась вместе с возможностью `мобильная-разработка`.

## Факт

У мобильного приложения зелёный тест почти ничего не значит. Тест проверяет
функцию, а пользователь видит экран: кнопка уехала за край, текст обрезан на
второй строке, отступы поехали на маленьком экране, вместо данных — заглушка.
Всё это проходит мимо зелёных тестов и видно только на снимке экрана.

Поэтому петля заканчивается не кодом возврата, а **прочитанным снимком**:

```bash
mobile-loop            # сборка → установка → сценарии → снимок → след
```

Скрипт печатает путь к PNG и прямо требует его открыть. Отчёт «петля зелёная»
без просмотра снимка — это «тест зелёный» вместо «работает», то есть нарушение
И-4. След петли пишется в `$LOG_DIR/mobile/последняя-петля.json`; гейт коммита
проверяет, что петля была свежей.

## Два запрета и их цена

**`gcloud firebase test` без `--timeout`** — сторож отменяет вызов. Бесплатная
квота Test Lab: 60 минут в сутки на виртуальных устройствах, 30 на физических,
дальше поминутно со счёта владельца. Единственный разрешённый вход — `ftl-run`,
в нём потолок берётся из паспорта возможности.

**Ручной запуск `emulator -avd`** — сторож отменяет. Эмулятор, поднятый в
текущем ходе, умирает вместе с ходом; поднятый второй раз — забирает вторые
2 ГБ и уносит сервер вместе с сессией агента. Вход один: `emu-start`
(идемпотентен, ждёт настоящей загрузки ОС, держит сервисный лок).

## Что отличать при разборе

- «устройство есть» ≠ «ОС загрузилась»: `adb devices` отвечает раньше, чем
  `sys.boot_completed=1`. На этом ловятся все первые прогоны.
- красный сценарий может означать «негде запустить», а не «сломано» —
  группировать падения по ПЕРВОЙ СТРОКЕ ошибки.
- `sdkmanager --licenses` без `yes |` ждёт ввода вечно: со стороны это выглядит
  как «агент замолчал».

## Где полные правила

Скилы `mobile-testing` (петля и отчёт), `android-env` (окружение и его беды),
`mobile-release` (релиз и граница с владельцем). Что не может агент —
`docs/возможности/мобильная-разработка-РУКАМИ.md`, владельцу вложением.
