## Снятие возможности

Отключение (скилы исчезают, запреты и уборка перестают действовать):

```bash
bash scripts/vozmozhnost.sh снять мобильная-разработка
```

Что останется на диске и как снести это руками — **решение владельца, не сессии**
(И-1: сессия не удаляет то, что стоило времени и денег):

```bash
rm -rf ~/android ~/.android ~/.gradle          # SDK, образы, кеши сборок (~20 ГБ)
rm -f ~/bin/emu-* ~/bin/mobile-loop ~/bin/ftl-run
rm -f ~/.config/harness-mobile.conf
rm -rf ~/.maestro
npm uninstall -g eas-cli
sudo apt-get remove --purge google-cloud-cli qemu-kvm openjdk-17-jdk
# блок «harness-mobile» в ~/.bashrc убрать вручную
```

Записи в `память/` и строки в `.gitignore` не удаляются автоматически: память —
история проекта, а не настройка.
