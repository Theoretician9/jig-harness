# Установи меня

Это задание для Claude Code, который уже работает на машине. Человеку читать
не обязательно: дайте своему агенту этот репозиторий и скажите «поставь
харнес по УСТАНОВИ-МЕНЯ.md».

Второй способ установки — для тех, у кого агент уже есть. Первый (чистая
машина, где нет ничего) — `README.md`, раздел «Установка».

---

## Что от тебя требуется

Поставить харнес на эту машину его собственным установщиком и довести до
состояния «смена работает, владелец видит канал». Установщик уже написан и
проверен — своей установки не изобретай.

## Порядок

1. **Проверь, что машина подходит.** Ubuntu 22.04/24.04, systemd и cron живы,
   есть sudo без пароля или пароль у человека под рукой:

   ```bash
   . /etc/os-release && echo "$PRETTY_NAME"
   systemctl is-system-running; systemctl is-active cron
   ```

   Не Ubuntu или нет systemd — скажи человеку прямо и остановись: установщик
   ставит юниты и расписания, без них харнеса не будет.

2. **Посмотри, что спросят.** Установщик задаёт три вопроса: имя проекта
   латиницей, токен бота от BotFather, часовой пояс ВЛАДЕЛЬЦА. Каталоги он
   выводит сам (`/opt/<имя>` и `/etc/<имя>/secrets`) — другие пути задаются
   переменными `PROJECT_DIR` и `SECRETS_DIR` перед запуском. Свой chat_id
   человек не переписывает: бот возьмёт его из первого сообщения.

   Спроси у человека имя проекта и пояс СРАЗУ, одним сообщением, и предупреди,
   что понадобится токен бота: он создаётся в Telegram у @BotFather за минуту.

3. **Прогони вхолостую** — это ничего не меняет и показывает каждый шаг:

   ```bash
   sudo bash USTANOVIT.sh --dry-run
   ```

   Упало — читай имя шага и чини причину, а не обходи установщик руками.

4. **Ставь.** Прогон долгий (apt, node, Claude Code), запускай фоном и жди по
   итоговой строке лога, а не сиди в нём:

   ```bash
   setsid nohup sudo bash USTANOVIT.sh > /tmp/ustanovka.log 2>&1 < /dev/null &
   ```

   Токен бота установщик спросит скрытым вводом — если ты запускаешь фоном,
   положи токен заранее в `$SECRETS_DIR/tg_bot_token` (владелец 0600) и запусти
   с `--resume`: тогда вопроса не будет.

5. **Доведи ручные шаги.** В конце установщик печатает блок «ОСТАЛОСЬ РУКАМИ»
   — это то, что не может сделать ни он, ни ты: вход по подписке Claude,
   сопряжение бота, первый промпт новой смене. Передай эти строки человеку
   ОДНИМ сообщением, по одной строке на действие, и дождись, что он их сделал.

6. **Проверь живьём, а не по логу.** Прогон чек-листа:
   `razrabotka/ЧЕК-ЛИСТ-ПРИЁМКИ.md`, раздел А. Минимум, который обязан быть
   зелёным:

   ```bash
   systemctl is-active harness-agent harness-dispatcher
   crontab -l -u agent | wc -l          # расписаний столько же, сколько заданий в реестре
   sudo -u agent bash <PROJECT_DIR>/scripts/vorota.sh   # ворота
   ```

7. **Скажи человеку итог числом:** что поставлено, сколько ворот зелёных,
   что осталось за ним. Без пересказа своих шагов.

## Чего не делай

* Не правь файлы харнеса «чтобы заработало» — у него свои сторожа, и правка
  переживёт установку только в пакете. Нашёл дефект установщика — скажи
  человеку и почини ПРИЧИНУ в `USTANOVIT.sh`.
* Не ставь ничего мимо установщика: пакеты, юниты и расписания он ставит сам и
  проверяет за собой.
* Не пропускай проверки шага. Установщик останавливается на первой же
  непройденной — это не помеха, а его работа.
