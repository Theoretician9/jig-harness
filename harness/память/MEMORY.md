# MEMORY.md — указатель памяти проекта

Грузится каждую сессию. Содержимое записей здесь НЕ дублируется — только
таблица срабатываний и указатель. Записи — файлы рядом, один факт = один файл.

## ТАБЛИЦА СРАБАТЫВАНИЙ: когда → что проверить

| когда происходит вот это | проверить себя |
|---|---|
| меня спросили, что было с задачей / почему встал демон / сколько отказов — или тянусь к `grep` по журналам | `python3 scripts/events.py status\|task <id>\|refusals\|lost`: ответ в бюджете токенов, а не поток строк |
| пришло сообщение владельца, собираюсь начать работу молча | сначала ack ≤30с в канал — [[feedback-communication]] |
| отправил «сейчас посмотрю/сделаю» и хочу закончить ход | анонсировал — продолжай, ход не кончен — [[feedback-communication]] |
| хочу задать вопрос или показать варианты | сообщением в канал с номерами, не интерактивным инструментом — [[feedback-communication]] |
| собираюсь отправить владельцу путь к файлу на сервере | владелец путь не откроет — вложением — [[feedback-communication]] |
| пишу шестой `if` под новый частный случай | неверная структура данных, не место для `if` — [[feedback-code-bar]] |
| тесты позеленели и тянет отчитаться «готово» | «тест зелёный» ≠ «сделано»: живая проверка, статус `test` — [[feedback-test-not-done]] |
| сторож отменил команду и тянет обойти его | сторож — источник истины; читать причину, не обходить — [[feedback-command-bans]] |
| собираюсь запускать `claude`/`pytest`/`docker` из скрипта или фоном | сверить с запретами и их причинами — [[feedback-command-bans]] |
| собираюсь выкатывать, ротировать сессию или делать необратимое | это развилка полуавтомата: анонс и подтверждение — [[feedback-semi-auto]] |
| анонс отправлен, хочется начать, «пока владелец читает» | без записи согласия в confirmations.jsonl действия нет — [[feedback-semi-auto]] |
| закончил шаг пайплайна (спека готова, тесты красные, код на ревью, выкачено) | обновить SESSION-HANDOFF за сегодня — [[feedback-handover-discipline]] |
| берусь за архитектуру, крупный рефакторинг или сложный баг | поднять усилие: /effort max до старта — [[feedback-effort-max]] |
| ловлю себя на «simplest / should I continue / not my changes» | маркер среза угла: перечитать файл, обосновать, продолжить — [[feedback-effort-max]] |
| собираюсь читать в контекст большой файл, лог или «все файлы подряд» | обработать скриптом, в контекст — вердикт — [[feedback-data-via-scripts]] |
| пишу тест/гейт или читаю в чужой описи «зелёный, неудач 0» | проверка обязана создавать своё условие, а не совпадать с машиной — [[a-check-creates-its-own-condition]] |
| собираюсь удалить файл внутри data/backup/secrets — «он же один» | И-1 про потерю данных, а не про рекурсию: решает владелец — [[i1-covers-single-file-deletion]] |
| пишу код, шлющий текст в tmux-панель агента | без `-l --` tmux примет текст за имя клавиши, Enter — отдельным вызовом — [[tmux-send-keys-takes-key-name]] |
| пишу скрипт, который копирует пачку файлов в чужое дерево | права проверить ДО первой записи: полуобновлённое дерево хуже необновлённого — [[a-half-updated-tree]] |
| правлю файл харнеса (scripts/, harness/, CLAUDE.md, settings.json) | править ПАКЕТ и разложить: правка только в проекте умрёт при раскладке — [[the-package-is-the-source-of-the-layout]] |
| собираюсь сохранить копию конфига рядом с оригиналом в *.d/ | каталог конфигов — список включённого: копия станет вторым конфигом — [[backup-next-to-config]] |
| беру лок дескриптором и запускаю демона (tmux, агента) | потомок наследует дескриптор и держит лок вечно — сторож мёртв и молчит — [[lock-leaked-into-a-child]] |
| пишу в shell присваивание с кириллицей в имени переменной | bash такие имена не берёт и печатает ЗНАЧЕНИЕ в ошибку (так утёк токен) — [[cyrillic-in-bash-names]] |
| сторож прислал «заверши сессию и выйди» — тянусь к --rotate-now | смену уже ведёт он: доделать, закоммитить и выйти /exit — [[the-departure-was-not-ordered-by-me]] |
| дописал строку в системный конфиг (юнит, cron, sysctl) руками | кто скажет, что строка принята? неверная секция игнорируется молча — [[a-setting-ignored-in-silence]] |
| контекст близок к компакту / пришла команда ротации | STATE.md перезаписать, handover дописать — [[feedback-handover-discipline]] |
| владелец задал правило («всегда», «никогда», «я говорил», «не хочу») | занести ДОСЛОВНО в память/ORDERS.md, иначе умрёт с сессией — [[an-order-dies-with-the-session]] |
| собираюсь завершить свою сессию (выход, `/exit`, kill панели) | выход и подъём смены — одно действие: `session-warden.sh --rotate-now` — [[leaving-without-raising-a-successor]] |
| пишу условие «пока рядом человек — не вмешиваюсь» | у уважения обязан быть срок и мера, иначе механизм выключен навсегда — [[an-attached-client-is-not-forever]] |
| пишу ожидание в тесте (`rc == 0`, точная строка) | не зависит ли оно от того, кто запускает: прогнать из `env -i` и из-под юнита — [[a-test-that-depends-on-who-runs-it]] |
| проверяю живость агента через `pane_current_command` | сперва `tmux has-session`: выход агента закрывает панель вместе с сессией — [[exit-closes-the-pane]] |
| завожу резервный путь (второй демон, `Restart=always`, таймер вместо cron) | выписать, что делал прежний путь ПОМИМО главного, и провести каждый пункт по новому — [[a-new-carrier-without-the-duties]] |
| пишу условие сигнала («очередь непуста», «задач не в done больше нуля») | при какой ЗДОРОВОЙ жизни оно тоже истинно? тогда сузить признак и завести различение в ДАННЫХ — [[a-signal-that-does-not-discriminate]] |
| пишу пробу механизма и зову его путём, вшитым от корня репозитория (`КОРЕНЬ / "scripts" / …`, `OBERTKA="scripts/…"`, спецификация `importlib`) | тогда проба судит БОЕВОЙ файл, и испорченная копия мутации до неё не доходит: три пробы одной смены остались зелёными на 7, 3 и 3 мутациях — дать пробе дверь (путь копии приходит из окружения) и назвать её в данных мутаций — [[probe-loads-the-live-mechanism]] |

## Тон общения — отдельным документом

Как говорить с владельцем, живёт в `память/TONE.md`: его пишет агент по замеру
живой речи (демон `ton-watch.sh`), он грузится в каждую сессию через `@`, и из
него же сторож канала берёт потолки длины. Это не запись памяти и не указание —
это документ, за которым надо следовать при каждом сообщении.
