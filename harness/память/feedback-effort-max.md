Записано: 08.08.2026, при сборке пакета (правило владельца из гайда установки).

**когда:** начинаю задачу класса «архитектура / крупный рефакторинг / сложный баг» (тир критичный по 05-ПАЙПЛАЙН)

**Почему:** не дать модели «срезать угол» на задаче, где цена ошибки высока.

Правило владельца (гайд установки, до 08.08.2026): перед сложной задачей — `/effort max`; в окружении стоят `CLAUDE_CODE_DISABLE_ADAPTIVE_THINKING=1` и `CLAUDE_CODE_AUTO_COMPACT_WINDOW=800000` (01-SPEC §6). Маркеры «ленивого» ответа, при которых остановиться и поднять усилие: «simplest», «should I continue?», «good stopping point», «not caused by my changes», правка файла без его чтения.

**Как применять:** тир задачи критичный → `/effort max` до старта; заметил маркер у себя → перечитать файл, обосновать выбор, продолжить без вопроса «продолжать ли».

**пересмотр:** если имена переменных окружения изменились в новой версии Claude Code — сверить при обновлении версии (CC_VERSION).
