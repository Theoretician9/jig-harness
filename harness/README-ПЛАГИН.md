# Харнес как плагин Claude Code

Каталог `harness/` оформлен как плагин: манифест `.claude-plugin/plugin.json`
(name=`harness`, version=`0.1.0`) + `skills/` рядом. Смысл: скилы, хуки и
команды ставятся и обновляются ОДНИМ набором с одним номером версии, а не
россыпью файлов по каталогам оболочки.

> ⚠️ **Сверить с текущей документацией плагинов при установке.** Манифест собран
> по лучшему знанию формата на 08.2026 (`.claude-plugin/plugin.json`; компоненты
> `skills/`, `commands/`, `agents/`, `hooks/hooks.json` подхватываются из корня
> плагина автоматически). Формат молодой и меняется; шаг установки обязан
> открыть актуальную документацию и поправить манифест, если поле переехало.

## Поставить одной командой

Из сессии Claude Code на сервере (каталог плагина — корень репозитория проекта,
`PROJECT_DIR` из `/etc/harness/install.conf`):

```
/plugin marketplace add <PROJECT_DIR>/харнес
/plugin install harness
```

(эквивалент через CLI: `claude plugin install ...` — точный синтаксис сверить
там же). После установки скилы видны агенту по `description` из frontmatter —
условие срабатывания каждого начинается с «когда…».

## Обновить

1. Правка вносится в главу `UNIFIED/NN-*.md` (тела скилов руками не правятся —
   два источника истины запрещены).
2. `python3 harness/SBORKA-SKILOV.py` — перегенерация `skills/`.
3. Поднять `version` в `.claude-plugin/plugin.json` (например, 0.1.0 → 0.2.0) —
   смена версии и есть обновление набора.
4. Переустановить/обновить плагин той же командой установки.

## Что в наборе

| Компонент | Где | Примечание |
|---|---|---|
| Скилы (12 шагов пайплайна) | `skills/<имя>/SKILL.md` | генерируются из глав; каждый пишет вызов в `$LOG_DIR/skills.jsonl` |
| Хуки-сторожа | `hooks/` | сейчас подключаются через `hooks/project-settings.json` → `.claude/settings.json` проекта (01-SPEC); перенос в плагинный формат `hooks/hooks.json` — при сверке с документацией |
| Команды | — | на старте нет; появятся — каталог `commands/` в корне плагина, войдут в тот же набор |

Демоны (`demons/`) и конфиги (`/etc/harness/*.conf`) плагином НЕ являются —
они ставятся установкой (01-SPEC) и живут вне оболочки.
